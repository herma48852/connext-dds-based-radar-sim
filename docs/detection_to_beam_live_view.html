Connect to DDS through Web Integration Service

The service owns the DDS participant and readers. This page binds those readers sequentially to one WebSocket and receives JSON B_PUSH messages.

Prerequisite: Start Web Integration Service with config/radar_live_view_wis.xml and WebSockets enabled. Serve this file from its document root for a same-origin connection. Direct file:// loading may cause the REST setup request to be blocked by browser origin policy. The supplied configuration uses appendable-type projections, so iq_samples and azimuth_pattern_db never cross the web boundary.
Future Connext Studio host-injection contract A Studio custom-view host can bypass Web Integration Service and call window.radarDetectionBeamView.ingest(topicName, data, metadata) for every valid sample. Topic names are the four names shown above. The same correlation engine and UI are used.
