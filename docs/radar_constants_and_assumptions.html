Radar constants & modeling assumptions

A presentation-ready reference for the waveform, array, search raster, receiver, detector, measurement, tracker, and data-rate constants actually used by the simulator.

01 / SCOPE

How to read this page

implemented is a literal code value; derived follows from other constants; calibrated is a demo engineering choice.

Physical frame

  • Monostatic radar: the same modeled aperture transmits and receives.
  • Range is three-dimensional slant range, not ground range.
  • Ship-relative azimuth is clockwise: bow 0°, starboard 90°.
  • Track positions and velocities are Earth-aligned ENU Cartesian values.

Signal abstraction

  • Complex baseband I/Q with independent Gaussian noise.
  • Pulse-compressed range is represented by discrete cells.
  • Target return is a voltage-like square-root radar-equation model.
  • Ten pulses are integrated noncoherently per search dwell.

Authority

  • Values below are transcribed from the linked implementation headers.
  • Derived values use the exact speed of light constant in the code.
  • If this page and source ever disagree, the source code is authoritative.
  • The detailed rationale remains in EFFECTIVE_RANGE_PROCESSING.md.

05 / RECEIVER

Target voltage and I/Q synthesis

The model preserves the radar equation’s range and RCS scaling while absorbing omitted transmit-power, propagation, loss, and receiver-scale constants into one arbitrary-unit calibration.

Target amplitude
A = K factive P(offset)
· √RCS / R²

Voltage-like arbitrary simulator units.

Calibration
K = 299,792,458

Wavelength-scaled from a 3.0×10⁸ reference at 10 cm.

Complex sample
I = A cosφ + NI
Q = A sinφ + NQ

Independent noise is added to both components.

Noise model
NI, NQ ~ 𝒩(0, 0.05²)

Complex-noise RMS magnitude is 0.07071.

07 / MEASUREMENT & TRACKING

09 / LIMITS

What the constants do not model

These omissions define the boundary of valid interpretation more strongly than another decimal place on any constant.

Propagation & environment

  • No atmospheric attenuation, terrain, sea state, multipath, or ducting.
  • No rain/weather volume returns, clutter map, interference, or jamming.
  • No receiver saturation or detailed transmit leakage/recovery.
  • No calibrated system loss or operational link budget.

Target & signal statistics

  • Constant target RCS; no aspect dependence or Swerling fluctuations.
  • No Doppler processing or radial-velocity measurement.
  • No fractional-delay matched-filter interpolation.
  • No modeled probability of detection; noise alone makes near-threshold outcomes stochastic.

Angle & tracking

  • One-dimensional azimuth array factor; elevation is a three-bar label.
  • No monopulse or continuous sub-beam angle estimate.
  • No adaptive CFAR training/guard cells or calibrated operational Pfa.
  • Published covariance is latest-measurement geometry, not a propagated Kalman posterior.
